# Vocabulaire de la conversation avec Mémo

Convention approuvée par le propriétaire le 17 octobre 2026, pour les textes Entreprise : présentation, leçons, activités, questions, cartes et définitions.

- **Prompt** : le message écrit à un assistant IA pour lui expliquer ce qu'on veut obtenir. Donner cette explication dès le démarrage, puis employer « ton prompt », « modifier le prompt », « un prompt modèle ».
- **Assistant IA** : le logiciel avec lequel on échange, comme ChatGPT ou Claude. Garder « IA » après « assistant » pour éviter la confusion avec une personne. Dans un cas consacré à un produit précis, son nom convient aussi. Mémo reste le compagnon pédagogique, distinct du logiciel utilisé dans les exemples.
- **Brief** : la description du besoin, du public, des informations et du résultat attendu. Le prompt est le message écrit à partir du brief. Les deux ne sont pas des synonymes systématiques.
- **Outil** : conserver ce mot courant. Expliquer « tool » si le lecteur le rencontre dans une interface ; inutile de remplacer chaque occurrence d'outil par un mot anglais.
- **Demande** : garder le mot pour les demandes clients, d'achat, de devis ou d'inscription. Le verbe « demander » reste naturel. Un dossier client ne devient pas un prompt.

## Inspection du 17 octobre 2026

Les 40 leçons et leurs 39 activités guidées ont été parcourues pour distinguer ces usages. La première mission présente ChatGPT et Claude comme exemples de logiciels et explique le prompt avant son emploi. La deuxième rappelle cette explication. Les cartes, définitions et textes de présentation sont harmonisés. Une définition locale de prompt est ajoutée à la première mission ; l'entrée historique de la deuxième conserve son ID et détecte prompt plutôt que toutes les demandes.

Le brief de réalisation peut servir à une personne technique aussi bien qu'à préparer un prompt. Les demandes d'achat et d'inscription gardent leur sens métier. Les documents sources et leurs téléchargements restent inchangés.

Comparaison structurelle : 40 leçons, 120 cartes, 11 évaluations ; identifiants, prérequis, bonnes options, sources et branchements d'activités conservés. `npm test` : 260 tests réussis, dont la couverture des définitions locales. `npm run build` : réussi, avec l'avertissement préexistant de taille de bundle. Recette des vrais composants avec une organisation fictive, sans modifier de compte réel. Cette inspection ne constitue pas une étude auprès de salariés.
